# LampsModern Homepage Banner Skill

A working skill repository for planning, generating, and archiving the two large homepage hero/slideshow banners on LampsModern UK.

## Main files

- `SKILL.md` — authoritative workflow and operating rules
- `references/decision-logic.md` — market/weather/category decision framework
- `references/copy-rules.md` — title, supporting line, CTA, offer rules
- `references/visual-rules.md` — scene, gradient, colour, CTA and image-generation rules
- `history/banner-history.md` — human-readable historical banner log
- `history/banner-history.csv` — tabular historical record migrated from the historical spreadsheet

## Core operating principle

When Evelyn says the homepage banner needs changing:

1. use the request date + next 10 days
2. research relevant UK context
3. propose a primary promotional banner and a secondary thematic banner
4. give complete copy + category + rationale for each
5. generate **two separate images**
6. after confirmation, append both to history

This repository is for homepage hero banners only. It is not the EDM banner workflow.
