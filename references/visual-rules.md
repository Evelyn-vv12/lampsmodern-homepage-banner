# Visual Rules

## Base visual direction

- colour image, not monochrome
- realistic modern UK home environment
- premium but believable
- product and scene must feel naturally matched
- avoid showroom/CGI perfection

## Left copy area

Reserve roughly the left 30% for copy.

Use a:
- dark/black **translucent gradient**
- not a solid opaque black rectangle
- background scene should remain faintly visible underneath

Default copy colour:
- white

## Accent colour

Do not make gold the automatic accent.

Choose a restrained accent based on the scene:
- muted blue
- soft rose
- restrained neutral
- low-saturation warm tone

The overall page should still fit LampsModern’s black/white site direction.

## CTA treatment

CTA should have:
- clear button/outlined treatment when appropriate
- right-pointing arrow
- strong readability on the dark gradient

## Prohibited default elements

Do not add:
- trust icon row
- UK Delivery
- warranty icons
- returns icons
- date range
- decorative badges
- excessive sale stickers

## Image-generation mapping

Strict rule:

**1 theme = 1 standalone banner image**

Two themes must be generated and delivered as two separate image files.

Never combine both themes into:
- one vertical stacked image
- one split-screen final banner
- one design-board image

unless the user explicitly asks for a comparison board.
