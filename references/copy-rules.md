# Copy Rules

## Required structure per banner

Every banner has:

1. Main Title
2. Supporting Line
3. CTA

Primary promotional banner also includes the offer/code.

## Main Title

The title should:
- be short enough for a homepage hero
- communicate one idea
- fit the next-10-day context
- avoid generic filler
- differ clearly from the other banner in the same refresh

Example:
**A Brighter Welcome Home**

## Supporting Line

A short sentence must sit under the title.

Example:
**Outdoor lighting for changing weather.**

This is an example, not a fixed template.

The supporting line should explain the scene/theme rather than repeat the title.

## CTA

CTA should be specific to the banner and include an arrow in the visual.

Examples:
- Explore the Collection →
- Explore Outdoor Lighting →
- Shop Ceiling Lights →
- Shop the Sale →

Do not default every banner to the same CTA.

## Promotional copy

For the primary banner:
- offer tiers should be easy to scan
- codes should be clear
- thresholds should have a commercial reason

For the secondary banner:
- no discount code by default

## Do not add by default

- promotional date line
- trust icons
- UK Delivery / 2-Year Warranty / Easy Returns
- long explanatory paragraphs
